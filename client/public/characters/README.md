# 🎨 캐릭터 에셋 제작 & 배치 가이드 (for Designers)

디자이너 분께서는 이 폴더 아래에 동물/캐릭터 종류별 폴더를 생성하고 이미지를 넣어주시면 됩니다.

---

## 📁 폴더 및 파일 규격 예시

```text
public/characters/
├── cat/                     # 고양이
│   ├── icon.webp            # 설정창/트레이용 프로필 컷 (권장 64x64)
│   ├── front.webp           # 전면 (정면 대기 상태)
│   ├── left.webp            # 좌면 (왼쪽 이동 상태)
│   ├── right.webp           # 우면 (오른쪽 이동 상태)
│   ├── surprised.webp       # 놀란 표정 (찌르기/알림 반응)
│   ├── busy.webp            # (선택) 집중 작업 중
│   └── sleep.webp           # (선택) 자리비움/잠자기
│
├── dog/                     # 강아지
├── rabbit/                  # 흰토끼
├── hamster/                 # 햄스터
├── fox/                     # 붉은여우
└── bear/                    # 아기곰
```

---

## 📐 제작 규격 가이드

1. **파일 포맷**:
   - **`.webp` 권장** (투명 배경 Alpha 채널 지원, 저용량·고화질)
   - `.png`, `.gif` 파일도 호환됩니다.

2. **해상도 및 캔버스**:
   - 권장 해상도: **64x64 px** (또는 48x48 px, 32x32 px)
   - 캐릭터 중심이 캔버스 중앙에 오도록 배치해 주세요.
   - 배경은 반드시 **투명(Transparent)**이어야 합니다.

3. **방향 및 표정 구성**:
   - **전면 (`front.webp` / `idle.webp`)**: 정면을 바라보는 기본 대기 모습
   - **좌면 (`left.webp`) / 우면 (`right.webp`)**: 좌/우 이동 시 노출  
     *(만약 우면만 제공되는 경우, 프로그램에서 좌우 반전하여 자동 처리도 가능합니다)*
   - **놀란 표정 (`surprised.webp` / `poked.webp`)**: 상호작용(콕 찌르기) 또는 알림 시 노출

4. **걷기 애니메이션 (프레임 불필요)**:
   - 별도의 걷기 프레임 나열 없이, 단일 컷(좌/우면)만으로도 프로그램이 **자연스러운 상하 바운스(Bobbing) 모션**을 자동으로 부여합니다.

5. **손/발 공통 테마 색상 안내**:
   - 손과 발은 앱 내 테마 색상(포인트 컬러)으로 공통 적용 및 동적 변경됩니다.
   - 따라서 캐릭터 원본 이미지에 손/발이 고정 색상으로 그려져 있지 않거나, 손/발 파츠가 별도로 분리되는 방식에 맞추어 주시면 자연스럽게 합성됩니다.

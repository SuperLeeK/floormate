# 🎨 Character Assets Guide for Designers

디자이너 분께서는 이 폴더 아래에 동물 종류별 폴더를 만들고 이미지를 넣어주시면 됩니다.

## 📁 폴더 및 파일 규격 예시

```
public/characters/
├── cat/                 # 고양이
│   ├── icon.png         # 설정창/트레이용 얼굴 컷 (32x32 또는 64x64)
│   ├── idle.png         # 제자리 대기
│   ├── walk_1.png       # 걷기 프레임 1
│   ├── walk_2.png       # 걷기 프레임 2 (2장 번갈아 재생)
│   ├── busy.png         # 집중 작업중
│   ├── sleep.png        # 잠자기
│   └── poked.gif        # 클릭 반응 (GIF도 가능)
│
├── dog/                 # 강아지
├── rabbit/              # 흰토끼
├── hamster/             # 햄스터
├── fox/                 # 붉은여우
└── bear/                # 아기곰
```

## 📐 제작 규격
- **해상도**: 32x32 px 또는 48x48 px (배경 투명 PNG 또는 GIF)
- **방향**: 기본적으로 **오른쪽(Right)**을 바라보도록 제작 (왼쪽은 프로그램에서 자동 반전)
- **우선순위**:
  1. `*.gif` 파일이 있으면 GIF 자체 애니메이션 재생
  2. `walk_1.png`, `walk_2.png` 프레임이 있으면 0.2초 주기로 프레임 교체
  3. 단일 `*.png` 정지 컷만 있어도 프로그램이 통통 튀는 산책 모션을 부여함
